# Desafio de Codigo - Java (intermediario)

## Descricao
Implemente um CRUD de usuarios salvando dados em um arquivo JSON local.

## Requisitos
* Implemente a solucao completa em Java
* Trate entradas invalidas com mensagens de erro claras
* Escreva pelo menos 2 testes unitarios
* Documente as funcoes principais

## Dicas
* Quebre o problema em funcoes menores antes de implementar
* Revise os conceitos de intermediario antes de comecar

## Criterios de Avaliacao
| Criterio      | Peso |
|---------------|------|
| Correcao      | 40%  |
| Legibilidade  | 30%  |
| Boas praticas | 20%  |
| Criatividade  | 10%  |

## Tempo sugerido
1 hora
